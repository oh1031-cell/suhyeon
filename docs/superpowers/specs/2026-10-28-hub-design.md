# 교실 서랍

사용자가 1번(PC 실행)을 선택하고 나머지 설계·구현을 위임했다.

후속 요청으로 GitHub Pages 공개 배포와 Firebase Google 로그인 일기장을 추가한다. 허브는 정적 배포 시 브라우저 저장소를 사용하고 로컬 서버 실행 시 기존 파일 저장을 유지한다. 일기는 새 Firebase 프로젝트의 계정별 Firestore 경로를 사용하며 기존 로컬 일기 자동 업로드는 하지 않는다. public 폴더만 Pages에 배포하고, GitHub 소스에도 실제 데이터와 인증 자격증명을 포함하지 않는다. 이 후속 요청이 아래 초기 로컬 전용 설계보다 우선한다.
Node.js 24+, 기본 모듈과 HTML/CSS/JS만 사용한다. 127.0.0.1:3210에서 실행한다.
차분한 녹색, 크림색 바탕, 한국어 시스템 글꼴, 카드와 왼쪽 탐색, 모바일 대응.

앱 검색·분류·즐겨찾기·직접 추가·수정·삭제를 제공한다. 일기장은 기존 폴더의 서버 및 DB를 사용하며 내용을 허브로 복사하지 않는다. 온교실은 기존 정적 소스를 복사하여 연결한다. 구구단 앱은 누락된 실행 파일의 복구 가능성을 확인하고 미완성 앱을 작동한다고 표시하지 않는다.

추가 도구: 시작/일시정지/초기화 가능한 타이머, 중복 제외 번호 추첨, 제외 번호를 지원하는 균등 모둠 편성, 날짜별 할 일, 요일별 시간표, 전체화면 아침 안내판. 이름·계정·학생별 평가 기능은 만들지 않는다.

앱 목록·할 일·시간표·안내 문구는 data/hub.json에 원자적으로 저장하며 JSON 백업·검증 후 복원을 지원한다. 일기 백업은 기존 앱의 기능을 사용한다. 온라인 공개·클라우드·외부 분석·외부 폰트는 사용하지 않는다.

대안: 온라인 허브는 여러 기기 접근에 유리하지만 로컬 일기장 실행은 별도로 필요하다. 사용자가 개인 PC 허브를 선택했다.

로컬 Host/Origin 검증, 정적 경로 제한, 크기·스키마 검증, 안전한 HTTP URL만 허용, 입력은 텍스트로 렌더링한다. 기존 앱은 별도 탭으로 열며 기존 브라우저 저장소의 기록은 자동 이관되지 않는다.
