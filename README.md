# 교실 서랍

초등교사의 웹앱과 수업 도구를 모은 개인 허브입니다. 정적 파일은 GitHub Pages에서 실행할 수 있으며, 개인 일기장은 Firebase Authentication(Google 로그인)과 Cloud Firestore를 사용합니다.

## 포함된 앱

- 하루의 조각: 기존 일기장 화면을 유지한 Firebase 연결 버전. 로그인한 본인 기록만 조회·저장합니다.
- 온교실: 기존 정적 소스의 복사본. 국어·수학·통합교과 활동 및 일정.
- 몽글마녀의 구구단 수프 공방: 기존 그림·문제 모델을 활용하고 누락된 실행 화면을 보완한 버전.
- 수업 타이머, 중복 제외 번호 추첨, 제외 번호를 반영한 균등 모둠 편성, 요일별 시간표, 아침 안내판, 날짜별 할 일.

## 실행과 저장

정적 배포는 `public/`만 게시합니다. 주소 하위 경로에서도 작동합니다. 허브 설정은 방문한 브라우저의 로컬 저장소에 저장되며 다른 방문자와 공유되지 않습니다. 브라우저 데이터를 삭제하기 전에 허브의 보관과 백업 화면에서 JSON을 내려받으세요.

로컬 실행은 Node.js 24 이상에서 `node server.mjs` 또는 `start.cmd`를 사용합니다. 주소는 `http://127.0.0.1:3210`이며, 이 모드에서는 허브 설정이 `data/hub.json`에 저장됩니다. 기존 로컬 일기장 실행 버튼은 옆 폴더 `로컬 서버 일기장 2`를 연결합니다. 원본 일기장 폴더와 DB는 변경하거나 공개하지 않습니다.

## Firebase 일기장

`public/apps/diary/firebase-config.json`에는 Firebase 웹앱의 공개 설정만 넣습니다. 웹 API 키는 관리자 비밀키가 아니며 데이터 접근은 Firestore 규칙과 Firebase 인증으로 제한합니다. 서비스 계정 키·관리자 토큰·OAuth 비밀키는 파일이나 저장소에 넣지 마세요.

계정별 경로는 `users/{uid}/entries/{entryId}`입니다. 검증된 Google 로그인 사용자와 경로의 UID가 일치해야 접근할 수 있습니다. 생성과 수정 모두 스키마·크기·타입·서버 시각을 검사합니다. 계정 삭제는 재인증 후 최소 삭제 차단 표식을 먼저 기록하고 일기를 배치 삭제한 뒤 Firebase 로그인 계정을 삭제합니다. 차단 표식은 오래된 인증 토큰의 경합 저장을 막기 위해 남으며, 일기 내용이나 이메일을 포함하지 않습니다.

실제 연결 프로젝트는 `classroom-drawer-oh1031-2026`입니다. Firestore Standard의 `(default)` 데이터베이스를 서울 `asia-northeast3`에 생성하고 접근 규칙을 배포했습니다. 결제 계정 없이 Spark 요금제를 사용합니다. Google 로그인과 웹앱 SDK 설정을 연결했으며, `oh1031-cell.github.io`를 로그인 도메인으로 사용합니다. 프로젝트를 운영하는 계정으로 Firebase CLI에 로그인해 배포합니다. 개인 계정별 일기 동기화를 위해 실시간 리스너를 사용합니다.

일기 내용은 GitHub나 Pages 정적 파일에 들어가지 않습니다. 초안과 일기 영구 오프라인 캐시는 사용하지 않으며, 초안은 현재 탭 메모리에만 남고 로그아웃·새로고침 때 지워집니다. 로그인은 브라우저 세션에만 유지됩니다. 프로젝트 관리자는 Firebase 관리 도구로 데이터에 접근할 수 있으며 종단간 암호화는 제공하지 않습니다.

기존 로컬 일기를 옮기려면 기존 앱에서 JSON 백업을 내보낸 다음, 로그인한 새 일기장에서 ‘로컬 백업 가져오기’를 선택하세요. 업로드 확인 후 새 기록으로 추가됩니다. 같은 파일을 재가져오면 중복될 수 있습니다. 백업은 1,000편·8MB 이하 단위로 나누어 내보내며, 여러 파일인 경우 모두 내려받고 각각 복원하세요. 가져오기가 중단되면 이미 저장한 기록은 유지됩니다.

## 검증

`pnpm install --frozen-lockfile --ignore-scripts` 후 `node --test`를 실행합니다. Firestore 규칙 테스트는 에뮬레이터가 없으면 건너뛰므로, 다음 명령도 별도로 실행해야 합니다(Java 21 이상 필요).

```sh
pnpm exec firebase emulators:exec --only firestore --project demo-classroom-drawer "node --test test/firestore.rules.test.mjs"
node scripts/security-audit.mjs
```

GitHub Actions는 일반 테스트와 Firestore 에뮬레이터 공격 테스트가 성공한 뒤 `public/`만 Pages에 배포합니다. Firebase 관리 자격증명은 Pages 배포에 필요하지 않습니다.

## 개인정보

데이터·백업·DB·인증 토큰·로컬 로그·환경 파일은 업로드 목록에서 제외합니다. 일기장의 자세한 저장·삭제 안내는 앱의 개인정보 처리 안내에서 확인할 수 있습니다. 학생 이름이나 상담 기록을 수집하는 기능은 제공하지 않습니다.
